Pick a record

Each record is one fact the next session is handed — a memory file beside the ledger. This page is where a record gets corrected without opening the file: read it as it is, change it, commit it through the same gate check runs.

How to read this page
hook
The one line under a record's name in the rail. It is the line the index carries and the first thing a session reads about the record, so it is shown before the body.
Current
The record exactly as it is on disk. Read-only.
Proposed
Your version. Starts identical to Current; Save and commit lights up the moment they differ.
Save and commit
Writes the file and commits it to the memory repo in one step. The write goes through the store's gate: a link that no longer answers or a hook the index has lost is refused, and the file stays as it was. If the record changed on disk while you were editing, the save is refused and your edit is kept on screen.
