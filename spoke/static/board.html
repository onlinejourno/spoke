    How to read this map

    The map is drawn from the ledger — the record of what was decided, deferred, blocked or found across the projects. It shows what needs attention and why, so that nothing waits in a chat window for someone to remember it.

    hub
    The node this lens anchors on. On the product lens every product is a hub; on the decision lens every decision is.
    spoke
    A node drawn around a hub because a relation joins them. The same node can be a spoke of several hubs; it is drawn once.
    lens
    A question asked of the same graph. Switching lens re-hubs it — nothing is copied, and no hub is the real root. The centre is the project itself: a label, not a node, because nothing here is the root.
    detail
    How much of the graph is drawn: hubs only, then each further layer of node types. It adds; it does not magnify. Past the point where the map fits, it scrolls.

    A flag is computed when the map is drawn, never stored. It names its origin — the node it comes from — and the rail above groups by that.

    blocked
    Something is waiting on something else. A block travels the whole chain: if A waits on B and B on C, A is blocked by C.
    deviates
    Open work under a decision that is on hold — it is going on while the thing governing it is stopped.
    held
    A decision on hold reaches this node directly. A hold is a scope, not a chain: it reaches one hop and stops.
    unruled
    Deferred, abandoned, deviated or superseded with no ruling written — closed without saying why.
    stale
    Not updated for longer than its state allows. A block goes stale soonest; something done is re-verified, not decayed.
    unmet
    The node says something should be observably true — a URL answers, carries some text, is fresh — and the last scheduled check found otherwise, or no check has run yet. Nobody having looked is not the same as it being true.
    unchecked
    The node carries a checklist and items on it are still open. It cannot be closed until they are ticked; that is what a checklist is for.
    absent
    On the capability lens only: a capability some products have and this one lacks. What is missing, not what is broken.

    Every flagged node carries the same signal three ways — colour, shape and the badge — so it survives greyscale, a printout and colour-blindness. The key along the bottom is drawn by the same code that draws the map.
