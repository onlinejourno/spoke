Nothing to score yet

This project has declared no capability axes, so there is no grid. Declare the first one and this page becomes a scorecard:

spoke projects axes --set 'reliability=Reliability:30'

One axis per --set, as key=Label:weight. There is deliberately no built-in list: the axes that matter are the project's, not this tool's. Once one exists, the legend and every node's row appear here.

How to read this

On this page colour means the score. On the board colour means severity. Two different encodings — don't carry one across.

Score

    Darker is higher. Every cell also carries the number and a bar, so the score survives greyscale, a printout and colour-blindness.

    Basis — where the number came from

    measured
    Somebody observed the live thing and wrote down what they saw. Only these count toward a composite.
    asserted
    Claimed — from a plan, a README, a belief. Nobody looked.
    unverified
    Explicitly could not be observed, and why.
    not scored
    Nobody has assessed this axis. This is not a zero. A zero is a finding; this is an absence.

    Freshness — whether it is still current

    A score that no longer counts carries a heavy stripe along the top of its cell and says so in words. The stripe never carries it alone — these are the words:

    current
    Observed recently enough to still stand.
    stale · age · does not count
    Measured, but longer ago than this project's threshold (—), with the cell saying how long ago. A stale measurement stops counting toward the composite, exactly as an unmeasured axis does — so a composite can rise when one ages out. Every composite says what did not count and how old it was.
    undated · does not count
    Measured, with no observation date at all. There is no way to tell it from current, so it does not count either.
    not applicable
    An asserted or unverified score never goes stale: neither was an observation, so no date can make it untrue. They stay visible and keep saying what is wrong with them.
